- Java 17+ (`options.release` 17) with the Gradle wrapper (checksum-pinned in `gradle-wrapper.properties`); pin every plugin and dependency exactly and prefer the standard library.
- Logic lives in plain classes (`Greeting`, `App.run`); `Main` stays a thin entry point that calls `App.run` and exits with its code.
- Commands read arguments, write results to the `Appendable` they are given and errors to stderr; exit 0 on success, non-zero on failure.
- Compile with `-Xlint:all -Werror`; format with Spotless and google-java-format (`just fmt` writes, `just lint` only checks).
- Tests use JUnit 5 and call `App.run` with in-memory writers: deterministic, no network, no real home directory.
- Validate arguments and file paths before use; never build shell commands from input (use `ProcessBuilder` with an argument list).
- Settings and secrets come from environment variables; never hard-code, log or commit them.
- Publishing artifacts, release tags and reaching remote hosts need the user's approval.
