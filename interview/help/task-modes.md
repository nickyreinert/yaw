# Task tracking

- **Local only:** `TASKS.md` is the list; works offline; IDs like `T-012`.
- **GitHub only:** issues are the list; `TASKS.md` is a read-only copy (`just task sync`); IDs are issue numbers (`#34`).
- **Both:** `TASKS.md` stays the list; `just task sync` copies each task to an issue (one way).
- Team projects always use GitHub only.
- Example: a solo side project starts local; add GitHub when others join.
