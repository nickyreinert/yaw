Language and where it runs pick one ready-made stack: tools, checks and the files YAW creates.
A tailored stack fits a common pair (Python on your own server: FastAPI web app). Other pairs get a
basic stack with the standard tools of the language. A pair that does not work (Python inside
WordPress) is refused, with the places that language can run.
The toolchain must be on your computer (Go, Rust, a JDK, Xcode ...); yaw doctor tells you what is missing.
Example: a script for your own machine is "local"; a page on GitHub Pages is HTML & CSS on "static".
