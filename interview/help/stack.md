Language and place to run pick the stack profile (python-cli, node-cli, static-site, ...).
Each profile names the languages and places it fits; the profile that fits best is suggested.
If no profile fits uniquely (for example Go, Rust, Swift or Java, which have no profile yet),
YAW lists all profiles and you pick the closest; "auto" means the same: you choose later.
Example: a script for your own machine is "local"; a page on GitHub Pages is "static".
