# ADR-0024: `communication` and `standards` rendering details

- **Date:** 2026-10-21
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** low

## Context

Doc 04 describes both modules but not their questions, outputs and AGENTS.md lines.

## Decision

- `communication` asks the style questions and writes a five-rule section into AGENTS.md; a Claude output style only when length or register differ from the default; nothing in team mode (ADR-0013).
- A template that renders to whitespace produces no file and no part.
- `standards` writes `docs/standards.md` (baseline + profile overlay ≤ 20 lines) and one AGENTS.md pointer.

## Consequences

Quick and Standard include both modules.
