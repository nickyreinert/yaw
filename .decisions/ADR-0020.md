# ADR-0020: `yaw init` vertical slice: profiles, interview and pipeline details

- **Date:** 2026-10-20
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal

## Context

Step 3 renders profiles, runs an interview and verifies the result; the docs did not say how profile files reach a project or what init does without a terminal.

## Decision

- Profile files are owned by `core`: `just/<p>.just` with an import line, `.gitignore` part, a scaffold written once as `managed: false` and skipped when the repo has code.
- Each profile implements the uniform verbs; `check` = `lint typecheck test audit sync-check`.
- Rule-based profile suggestion; init = collect, confirm, apply, verify (`just setup && just check`); without a terminal `--answers --yes` is required.

## Consequences

Adding a profile is a folder plus an example and a smoke-test entry.
