# ADR-0018: Normalised hook event and session registry storage

- **Date:** 2026-10-20
- **Category:** Agents / Hooks
- **Status:** Accepted
- **Importance:** normal

## Context

Step 4 normalises payloads of three agents; doc 13 forbids storing prompt or response content; BD3 puts the session registry into `~/.yaw/yaw.db`.

## Decision

- One record per hook call with exactly `v, agent, event, nativeEvent, sessionId, cwd, modelId, modelIdSource, promptLength, tool, result, timing`; never prompt text, tool input or output.
- Handlers that need content get the payload in memory during dispatch only.
- `yaw.db` (`node:sqlite`, warning filtered): `schema_migrations`, `sessions`, `session_links`; numbered migrations; no other tables in phase 1.

## Consequences

Metrics and evaluation (phase 2) add tables by migration without touching the registry.
