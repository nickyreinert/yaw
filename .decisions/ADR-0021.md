# ADR-0021: Agent adapters and the hook dispatcher (Claude Code, Codex, Copilot)

- **Date:** 2026-10-20
- **Category:** Agents / Hooks
- **Status:** Accepted
- **Importance:** high

## Context

Step 4 needs one hook entry point for every agent, per-agent payload and output translation, and no double firing in Copilot, which also reads `.claude/settings.json` (H4, H7, H8).

## Decision

- `yaw hook <event> --agent <a> --module <m>`: one registration per module and event; normalise the payload, run the module's handlers, apply the output policy, log the content-free event.
- One shim command for all agents; never `async`; a missing shim is skipped silently.
- Claude: `.claude/settings.json`; Codex: `.codex/hooks.json` with translated matchers and a trust note; Copilot: no file of its own (it runs the Claude hooks; detected by `timestamp`).
- `yaw agents` renders the compatibility matrix.

## Consequences

Fields marked "assumed" must be re-checked with real recordings before v0.1 (#94).
