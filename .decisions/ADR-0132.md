# ADR-0132: Compact recipe steps: yaw run --compact, recorded in run.jsonl

- **Date:** 2026-11-08
- **Category:** Modules / Comfort
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `modules/compact/lib/run.js`, `core/render/kit.js`

## Context

kickoff/16-compact-output.md §4 L1 wraps the project recipes in a runner that condenses passing output. L5 asked yaw run to write its sizes to hooks.jsonl, but a recipe step has no agent, session or hook event, which the hook-event schema requires.

## Decision

- `yaw run --compact [--step] [--warn <regex>] -- <cmd>` (modules/compact/lib/run.js) decides at run time through resolveCompact: compact only with the `recipes` lever; YAW_VERBOSE=1 passes output through. Exit 0: `ok <step> (<n> lines, <s>s)`; with warnings: count, first 10, `… +<k> more warnings`; exit not 0: ANSI, progress and repeats removed, 40 head and 60 tail lines with a YAW_VERBOSE=1 hint; the exit code is kept.
- With the compact module enabled (committed or personal scope), renderProfiles wraps every body line of lint, typecheck, test, build and audit except plain echo lines and lines with `{{`; the line falls back to running unchanged when no kit is installed. The warning pattern is the profile's `compact.warnings`.
- Each compact run appends `{ v, ts, step, method, exitCode, rawBytes, outBytes, ms }` to ~/.yaw/logs/run.jsonl (same private file rules as hooks.jsonl), never output.

## Consequences

Teammates without YAW keep raw output; savings views (T-056) read run.jsonl next to hooks.jsonl. Warnings a passing step prints outside the profile pattern are hidden.
