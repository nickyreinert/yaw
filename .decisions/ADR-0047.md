# ADR-0047: Team setups can use a local Git remote without GitHub

- **Date:** 2026-10-23
- **Category:** Modules / Workflow
- **Status:** Accepted
- **Importance:** high

## Context

The user confirmed that a team may use Git with a repository in another local folder as its remote. Team collaboration must not imply GitHub. Earlier task and setup defaults in ADR-0010 and ADR-0032 assumed otherwise.

## Decision

Ask tasks.use-github in Quick and Full for solo, team and external-reviewer projects. An explicit false keeps tasks local and excludes automatic selection of github, ci and the GitHub-specific team enforcement module. Preserve all existing Git configuration, including a local bare remote. Without an explicit answer, existing team setups retain their GitHub defaults. Treat external reviewers consistently as team collaboration. Shared team instructions never embed personal chat language, autonomy, communication style or a Claude output style. Explicitly adding the GitHub team enforcement module selects shared instructions and GitHub tasks, overriding a solo project's task default, with a visible warning that existing local tasks are not migrated.

## Consequences

GitHub-backed Full teams retain issue, PR, ruleset and hook enforcement. Local-only teams use TASKS.md and normal Git commands, without GitHub-specific issue or PR enforcement. The Quick interview gains one GitHub selection question. CLI, form state and saved answers use the same choice.
