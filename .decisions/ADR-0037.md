# ADR-0037: php-web profile: plain PHP scaffold, check without Docker or database, never auto-suggested

- **Date:** 2026-10-22
- **Category:** Modules / Catalogue
- **Status:** Proposed
- **Importance:** normal

## Context

Y-6.4 adds php-web; doc 05 lists Plain PHP or Laravel, Docker Compose (php-fpm, nginx, MariaDB), phpstan, php-cs-fixer, PHPUnit/Pest, `migrate --pretend`, composer audit, Playwright, and shared hosting or a Docker host.

## Decision

Scaffold: plain PHP 8.2+ (Composer, PSR-4 `App`/`Tests`, strict types), one class in src/, a front controller in public/, PHPUnit tests, PHPStan level 8, PHP-CS-Fixer (@PER-CS2.0), exact-pinned dev dependencies. Laravel, MariaDB, Docker Compose, Pest, `artisan migrate --pretend` and Playwright wait for the full interview (step 7) and later ADRs; those verbs print not applicable. Gate: lint (php-cs-fixer dry run), phpstan, phpunit, `composer audit --locked`; no Docker, database or network beyond Composer/Packagist. No composer.lock is committed by the profile (it appears after just setup, as uv.lock in python-web); audit runs against the lock. deploy only prints a note: rsync/SFTP to a host needs the user. Guards block every `artisan migrate` and `db:wipe`/`db:seed` form (php, php8.x, ./artisan, sail, docker exec, env prefixes, --env=production, wrappers, chains) except `--pretend`; ssh/scp/sftp/ftp/lftp; rsync to a remote host (host:path, host::module, rsync://); DOCKER_HOST=, docker -H/--host/--context; docker push, --push. suggestWhen is empty: the interview has no PHP language choice (python, javascript, typescript, auto), so no fact is narrow enough and the user picks it from the list. The scaffold has no scripts that read project files, so no symlink handling is needed; PHP-CS-Fixer's finder does not follow symlinks by default. CI: php-web joins the profile matrix of kit-ci.yml; shivammathur/setup-php (SHA-pinned, PHP 8.2 floor, Composer 2, no coverage) is added there and in the profile fragment; fixtures lint_error.php and type_error.php live in test/profiles/php-web/.

## Consequences

A new project passes just check without Docker or a database; the profile is chosen manually until PHP is a language choice; deploy and migrations are inert or blocked; the php-web smoke test is skipped where php or composer is missing.
