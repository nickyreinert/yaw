# ADR-0074: Quick setup reuses personal preferences and requires confirmed project choices

- **Date:** 2026-10-28
- **Category:** Architecture / CLI
- **Status:** Superseded
- **Importance:** normal
- **Supersedes:** ADR-0072
- **Scope:** `core/interview/**`, `core/cli/init.js`, `core/web/**`, `interview/**`, `kickoff/**`
- **Tags:** kickoff, quick, interview
- **Superseded by:** ADR-0079

## Context

The user selected work packages 1 and 2 in kickoff doc 15 for implementation together: setup flow and terminal/browser interview. Quick currently repeats personal prompts and silently defaults language and runtime.

## Decision

Quick reuses valid saved personal preferences or documented defaults while confirming repository agents and requiring project purpose, language and runtime. Offer optional personal review through the terminal u menu and browser project review/Global Settings; saving remains an explicit action separate from presets. Full retains its deeper review with saved defaults. Essential empty or uncertain values cannot be skipped; browser drafts may remain incomplete, while Apply rejects missing or unconfirmed imported/planning choices. Preserve existing project values and section boundaries. Noninteractive --answers remains reproducible and byte-preserves confirmed proposal files under ADR-0019: no implicit machine-profile merge, no proposed proposals, and no silent filling of missing project facts. Amend ADR-0009 question selection, ADR-0042 expertise timing in Quick and ADR-0043 profile reuse/onboarding only; retain their other constraints and ADR-0054 stack mapping. No new hook output (ADR-0007), baseline modules or dependencies.

## Consequences

CLI, server and browser share a pure interview policy. Source labels and unresolved choices are transient review metadata; canonical answers stay compatible. Missing/partial/invalid profiles, optional save consent, loaded presets, incomplete drafts, browser handoff and explicit project overrides require regression coverage. Existing saved projects are not rewritten when global defaults change. Foundation generation and prompt/import expansion remain separate proposed work packages 3 and 4.
