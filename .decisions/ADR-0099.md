# ADR-0099: Interview wrappers retain shared checks and expose the file plan

- **Date:** 2026-10-30
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/**`, `core/interview/**`, `core/lib/coding-practices.js`, `modules/core/**`

## Context

The revised interview adds command-wrapper selection and a collapsible, context-sensitive project tree while reducing explanatory copy.

## Decision

Save arch.wrapper as off, shell, just or make, default just. Shell adds project.sh and Make adds Makefile, forwarding common commands to the existing stack recipes; Off adds no extra application wrapper. All modes retain YAW Just checks and preserve existing user files through normal reconciliation. Use the rendered preview for the interview-only file tree, with provisional paths clearly marked until required project answers are complete. Limit Purpose/Idea to 500 words in shared CLI/web validation. The collapsed LLM Support and local foundation prompt preserve ADR-0096's copy-only workflow.

## Consequences

Shell and Make still need Just for YAW's checks. File highlighting is local presentation state and does not run commands, provision environments or add hook output.
