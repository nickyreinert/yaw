# ADR-0104: php-cli profile: PHP command-line tools on your computer, split from php-basic (T-001)

- **Date:** 2026-10-30
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `profiles/php-cli/**`

## Context

T-001 replaces basic fallbacks per language and destination. PHP x local only had php-basic.

## Decision

- Scaffold: plain PHP 8.2+ (strict types, PSR-4 App/Tests), bin/app entry point calling App\Cli::run() with injected output and error streams, PHPUnit tests, PHPStan level 8, PHP-CS-Fixer, exact-pinned dev dependencies, no runtime dependency.
- Gate: lint, typecheck, test, composer audit --locked; no Docker, database or network beyond Composer.
- Guards: machine-wide Composer changes (global, self-update) and remote hosts (ssh, scp, sftp, ftp, rsync to a host).
- No sub-options: one scaffold fits; a PHAR build would be a later ADR. php-basic keeps serverless until that pair is tailored.
- suggestWhen stays empty.

## Consequences

A new project passes just check offline of any server. The smoke test also runs bin/app with and without arguments.
