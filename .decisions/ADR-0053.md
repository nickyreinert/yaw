# ADR-0053: Technical web workspace: website palette, global native session browsing, and user/project knowledge reader

- **Date:** 2026-10-24
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0052
- **Scope:** `core/web/**`, `modules/sessions/lib/import.js`

## Context

The first web redesign used promotional copy and exposed only registry history; the user asked for website-aligned styling, direct technical controls, all global sessions, and knowledge browsing in both scopes.

## Decision

Use the website cream/teal palette and shark wordmark with compact labels and a numeric overview. Sessions default to all history; read-only native Claude/Codex/Copilot discovery augments registry metadata in memory, cached 60 seconds, without importing or storing content. Apply filters and column sorting before pagination. Knowledge browsing reads only existing Markdown under user knowledge and current-project decisions/knowledge/spec roots, with scope/namespace/type/search controls, safe text-node rendering, bounded descriptor reads, and secret/symlink exclusion. User-scope browsing does not change project retrieval or namespace permissions.

## Consequences

No new persistence tables, dependencies, collection hooks or write endpoints. Existing explicit setup saves and authentication stay intact. The scan limits and data coverage are visible. supersedes the registry-only profiling and decisions-only memory UI in ADR-0052.
