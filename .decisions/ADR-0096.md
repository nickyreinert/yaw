# ADR-0096: Replace resumable browser reply imports with external interview recommendations and a local document kickoff

- **Date:** 2026-10-29
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0083
- **Scope:** `core/web/**`, `core/lib/setup-prompts.js`

## Context

The updated setup flow uses an optional external interview for setting recommendations and a single local-agent kickoff instead of importing a planning bundle through browser cards.

## Decision

Supersede ADR-0083 for browser setup and Settings kickoff. Show a copy-only optional interview prompt in Your project, automatically synchronized with answers. The external model returns Architecture and Workflow setting recommendations for manual entry. Review shows one final prompt, synchronized with validated effective answers and selected modules, directing the local coding agent to write Architecture, Data Model and UI/UX in the target project. Reuse that same final card after Apply. Remove browser Reply, import, refresh and provider-drafting controls. Preserve established document paths, existing work, project/personal separation and review of unresolved decisions. Existing CLI plan-import commands and validation remain supported separately.

## Consequences

Browser setup no longer transports generated document bundles or invokes a provider. Users can copy the final prompt before or after Apply; incomplete project facts disable the final handoff. No new hook output or provisioning approval is introduced.
