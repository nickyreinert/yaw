# ADR-0026: `git-hooks` module (lefthook, gitleaks)

- **Date:** 2026-10-21
- **Category:** Modules / Workflow
- **Status:** Accepted
- **Importance:** normal

## Context

Doc 04 asks for format, lint and a secret scan on commit; doc 14 plans lefthook for commit-msg and pre-push.

## Decision

- Use lefthook (single binary) with pre-commit jobs `secrets` (gitleaks on staged changes), `format` (`just fmt`), `lint` (`just lint`).
- Install explicitly with `just hooks-install`; never touch `.git/` on add or remove; never bypass with `--no-verify`.
- A missing gitleaks or lefthook at install (`yaw init`/`yaw add`) is a warning, not an error: selecting git-hooks prints "install <tool>: <command>" for each missing tool. At commit time the hook keeps warning only.
- A missing gitleaks warns instead of blocking; CI installs pinned, checksummed binaries.

## Consequences

Removal leaves an installed git hook that does nothing without the config.
