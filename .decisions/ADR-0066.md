# ADR-0066: Session programming-language fallback from local filenames

- **Date:** 2026-10-27
- **Category:** Memory / Sessions
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/**`
- **Tags:** improve

## Context

The session language filter showed Unknown for projects without an explicit YAW language, even when code was available.

## Decision

Keep an explicit configured project language authoritative. Otherwise use bounded local source-extension counts, falling back to recognizable root manifests. Do not read source contents, hidden folders, dependencies or symlinks. Ties are Mixed; unavailable projects, synced sessions and absent evidence stay Unknown. Apply the same hint to shared Global, Sessions and Improve filters; it describes current project code, not conversation language or historical session code.

## Consequences

Detection is a best-effort dashboard hint capped at 2000 entries and four directory levels. Existing metadata-only storage and explicit transcript-read rules in ADR-0018, ADR-0029 and ADR-0065 remain unchanged; ADR-0007 hook output remains unchanged.
