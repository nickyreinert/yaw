# ADR-0032: Setup depth: Quick and Full (Standard merged into Full); the mode controls output and records the starting depth

- **Date:** 2026-10-21
- **Category:** Modules / Catalogue
- **Status:** Proposed
- **Importance:** high

## Context

Step 5.10 asks for two setup choices that control generated output. On main, Standard and Full select the same modules, docs disagree with module.yaml (BD5 Quick list, sessions dependency, comfort asked item by item, phase-2 modules under Standard), and doc 02 says the mode changes only the questions shown.

## Decision

- Two choices (decided by the user): Quick = core, communication, standards, devenv, tasks, security; Full = Quick + git-hooks, github, ci, decisions, sessions, comfort, and team when the project is a team. Standard is merged into Full; `standard` stays a valid value with unchanged output and is no longer offered.
- The mode controls generated output: Full asks the Q, S and F questions; github and ci are on in Full and off in Quick; in Full they are off when the user says they do not use GitHub. Team projects are not asked: team mode always requires github (enforced); the remote can be local, where GitHub-only parts are skipped and local rules still apply. Hooks stay registered per module; the detail lists every module's hooks and skills per mode.
- Quick is a baseline: `yaw add` extends it and never changes the mode. The mode (answers.yaml#mode, manifest.json#preset) is the starting depth, not the current state; the installed modules come from the manifest.
- The 80-line AGENTS.md limit stays (not raised) and applies to Full; the next PR trims module rules into docs/spec or skills to fit Full and adds the line-count test.

## Consequences

Amends ADR-0009 (Standard and Full contents, comfort questions); its other parts stay Accepted. BD5 and docs 02, 03, 04 follow. ADR-0013 and ADR-0030 stay Proposed. A solo Full project renders 83 AGENTS.md lines on main, so that PR trims module rules first. Question 1.3 (prototype / MVP / product) maps to the choice in step 7.
