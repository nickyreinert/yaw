# ADR-0012: Skill distribution to Claude (generated copies) and the drift check

- **Date:** 2026-10-20
- **Category:** Agents / Skills
- **Status:** Accepted
- **Importance:** normal

## Context

Skills are authored once in `.agents/skills/`; Claude reads only `.claude/skills/`. Symlinks break in some checkouts and are refused by the path guard.

## Decision

- Render skills byte for byte to `.agents/skills/` and, for Claude, to `.claude/skills/`; both are managed module files.
- `yaw sync --check` re-renders the adapter files (skills, agent settings, hook shim) and fails on drift; it runs in `just check` through `sync-check`.
- A hand edit of an adapter file fails `just check`; personal Claude settings go to `.claude/settings.local.json`.

## Consequences

Copilot may see a skill twice (unverified); after a kit update `just check` reports drift until `yaw update` ran.
