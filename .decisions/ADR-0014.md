# ADR-0014: Kit repository and test layout

- **Date:** 2026-10-20
- **Category:** Governance / Repository
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0016

## Context

`node --test` without arguments runs every `.js` file below a `test/` folder, so helpers and sample projects would run as tests; docs disagreed on `tests/` vs. `test/` vs. `examples/`.

## Decision

- Layout: `bin/yaw`, `core/{cli,render,hooks,lib,schema}`, `modules/<m>/` (with `tests/`), `profiles/<p>/`, `examples/<profile>/`, `test/` (+ `helpers/`, `fixtures/<agent>/`), `.decisions/` for ADRs from step 5.6.
- `npm test` runs only `*.test.js` files in `test/`, `modules/*/tests/` and `profiles/*/tests/`.
- Tests create everything in temp folders with a clean environment.

## Consequences

Sample projects never run as kit tests; supersedes the interim layout of ADR-0016.
