# ADR-0030: comfort module: user-only hygiene, status line and notifications; personal config in ~/.yaw; last check status

- **Date:** 2026-10-21
- **Category:** Modules / Comfort
- **Status:** Proposed
- **Importance:** normal

## Context

Doc 11 leaves M7 (personal vs. committed), M8 (last just check not stored) and M14 (hygiene uncheckable) open; BUILD.md rule 5 allows no model-visible comfort output.

## Decision

- comfort hooks return only systemMessage or terminalSequence; two silent evaluation hooks record the last just check from the agent's Bash calls.
- Personal settings live in ~/.yaw/comfort.yaml (read-only for YAW), state in ~/.yaw/state/comfort; the statusLine setting is committed only in solo projects.
- Hygiene stays on by default but can be switched off: user.comfort, yaw hygiene off [--all].
- Notifications only after N minutes (default 3), closed payload without code, diffs or secrets, terminal and ntfy channels.

## Consequences

Status line shapes and Bash failure reporting rest on documented behaviour until live payloads are recorded (#94); Codex has no status line or Notification hooks; per-project overrides and more channels are left for later.
