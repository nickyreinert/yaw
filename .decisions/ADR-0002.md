# ADR-0002: Template engine: a tiny `<% %>` renderer

- **Date:** 2026-10-20
- **Category:** Architecture / Rendering
- **Status:** Accepted
- **Importance:** normal

## Context

Templates render Markdown, justfiles, CI workflows and shell; `{{ }}` collides with just, GitHub Actions and Jinja. No dependencies allowed. Rejected: JS template functions (escaping, logic in content), Mustache-style `{{ }}`.

## Decision

- Render with the built-in renderer (`core/render/template.js`): `<%= path %>`, `<% if %>`/`<% else %>`/`<% end %>`, `<% each list as x %>`, `<%%` literal.
- No expressions, filters or includes; compute values in JS before rendering. Only `*.tmpl` files are rendered; others are copied byte for byte.
- Build structured outputs (settings JSON, manifest) as data, never through text templates.

## Consequences

Other template syntaxes pass through untouched; templates cannot run code; logic beyond if/each moves into the module's JS.
