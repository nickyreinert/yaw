# ADR-0089: Search facet lists independently of Analytics session filters

- **Date:** 2026-10-29
- **Category:** Architecture / Rendering
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/assets/**`
- **Tags:** analytics, search

## Context

Long device, folder, project, language, agent and model lists need immediate narrowing without changing chart results.

## Decision

Place an accessible native search field above each shared facet list. Match labels and underlying values or paths without case sensitivity. Search only hides list options; retain All, checked values, session counts and existing session filters. Keep queries in memory per Analytics or Overview view across redraws; Reset clears them. Apply the same renderer to global views and the two workspace facets.

## Consequences

Users can find a choice before selecting it. Typing never filters sessions, changes the URL, or triggers backend requests.
