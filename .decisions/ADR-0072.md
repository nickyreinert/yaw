# ADR-0072: Quick reuses personal settings and establishes essential project facts

- **Date:** 2026-10-28
- **Category:** Architecture / CLI
- **Status:** Superseded
- **Importance:** normal
- **Scope:** `kickoff/**`, `core/interview/**`, `core/cli/init.js`, `core/web/**`
- **Tags:** kickoff, quick, interview
- **Superseded by:** ADR-0074

## Context

KICK-OFF.md open item 1 asks Quick to omit repeated personal questions while preserving a sound project proposal. The installer currently does not collect a profile and CLI Q questions still include personal preferences.

## Decision

Offer optional personal onboarding separately. Quick reuses saved personal values or documented defaults, confirms repository agents and establishes purpose, runtime and language/stack. Show answer provenance; missing essential project facts need a confirmed proposal or remain unresolved and block Apply. Explicit project overrides take precedence; preserve existing repositories and separate consent for profile and preset saving. This is a concept proposal only; current ADR-0009, ADR-0042 and ADR-0043 behavior remains until acceptance and implementation.

## Consequences

Requires matching CLI and browser behavior, saved-profile reuse and coverage for presets, handoff and noninteractive setup. Removing personal questions must not silently default project architecture. Installation remains usable without onboarding or a model.
