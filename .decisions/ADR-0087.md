# ADR-0087: Scope Analytics filters to workspace or global views

- **Date:** 2026-10-28
- **Category:** Architecture / Rendering
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0082
- **Scope:** `core/web/**`
- **Tags:** analytics

## Context

Workspace Analytics is already fixed to one project, so global discovery filters add noise and can hide sessions through stale URLs.

## Decision

Retain the shared cascading multi-select renderer, OR within categories and AND across categories, and canonical Analytics routes with Sessions aliases. Global Analytics and Global Overview show Device, Folders, Projects, Programming language, Agent and Model. Workspace Analytics shows Agent and Model beside period, date range and chart split controls; ignore and remove device/folder/project/language URL filters in this scope. Keep operations below the filters, in document flow. Preserve unavailable synced paths and backend session naming.

## Consequences

Workspace controls match their scope without silently carrying hidden global selections. Global views keep the full six-category browser.
