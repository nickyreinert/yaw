# ADR-0122: go-web profile: Go x self-hosted as a net/http service with a Dockerfile (T-001)

- **Date:** 2026-10-30
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `profiles/go-web/**`

## Context

T-001: Go x self-hosted. Pattern: ADR-0114 (rust-web).

## Decision

- go-web takes go x self-hosted. net/http ServeMux with Go 1.22 method patterns (GET /hello/{name}), NewHandler() tested with httptest, HOST/PORT, timeouts, graceful shutdown, GET /health, distroless nonroot Dockerfile.
- chi is not offered as an option: it adds a module, go.sum and network to the gate for little gain over ServeMux.
- Same gate and guards as go-cli plus image push and remote Docker guards; build writes bin/app and is part of check.

## Consequences

Standard library only, so no go.sum and an offline gate. The Dockerfile is never built by the kit and is unverified.
