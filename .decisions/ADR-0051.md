# ADR-0051: More language choices, a static runs-on option and option descriptions in the stack questions

- **Date:** 2026-10-23
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal

## Context

Issues #164 and #165: the language question offered only python, javascript, typescript and auto; "where should it run" had no option for static hosting (GitHub Pages) and the options (edge, serverless, ...) were not explained.

## Decision

arch.language adds kotlin, swift, go, rust and java; arch.runs-on adds static (static files only, no server code). Every option of both questions carries a one-line label shown next to the value in the terminal and the form. The runsOn fact vocabulary adds static. static-site is suggested for runsOn static; android-kotlin for language kotlin with runsOn app-store (or unknown). Languages without a profile (swift, go, rust, java, server-side Kotlin) give no suggestion: the user picks the closest profile from the list, which the stack help explains.

## Consequences

The answer schema and existing answer files stay valid; old values keep their meaning. ADR-0034 and ADR-0040 are amended: both profiles are now suggested for their narrow facts. New profiles for Go, Rust, Swift or Java can add suggestWhen entries without another interview change.
