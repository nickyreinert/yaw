# ADR-0060: Synced sessions appear in the Sessions pages

- **Date:** 2026-10-25
- **Category:** Architecture / CLI
- **Status:** Superseded
- **Importance:** normal
- **Supersedes:** ADR-0057
- **Scope:** `core/lib/data-sync.js`, `core/web/dashboard.js`
- **Superseded by:** ADR-0061

## Context

After a sync the other device's sessions were invisible: exported rows had only a hash and token counts, and the Sessions pages read only local data (ADR-0057 kept them separate). The user expects one set of charts.

## Decision

Rows of statistics sync also carry start time, length, agent, model and response-time figures; no title, project, path or id. The Sessions pages add other devices' rows (source synced, project 'synced · <device>'), drop any session this device also has, and never count one twice. Older vault rows without a start time stay in the Sync totals and are reported as uncharted. All other ADR-0057 rules stay.

## Consequences

Another device needs this version and one sync to publish dates, so charts fill after both devices updated. Agent and model names are exported. Synced sessions have no project folder, so folder and project views show them under their device.
