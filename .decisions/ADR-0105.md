# ADR-0105: Profile options: a profile.yaml option selects a scaffold variant; asked as a generated stack question arch.<profile>-<option>

- **Date:** 2026-10-30
- **Category:** Architecture / Formats
- **Status:** Accepted
- **Importance:** high

## Context

T-003: a language x runs-on pair picks exactly one profile (ADR-0054), but some pairs need a fork such as the framework (TypeScript x app-store: Capacitor, Expo, Electron, Tauri; PHP x serverless: Bref or container). profile.schema.json already had an unused options block. The free-text question arch.framework is retired (RETIRED_ARCHITECTURE): it is only kept so old answers stay readable and feeds prose into foundations and kickoff, so it cannot carry a validated choice.

## Decision

- profile.yaml options.<name> (lowercase id) has choices (value or {value, label, note}), default (one of the choices), optional label and hint, and scaffold: true for at most one option per profile.
- collectQuestions adds one choice question per option, id arch.<profile>-<option>, mode Q, when arch.language and arch.runs-on are the pairs of the profile, placed right after arch.runs-on; it is asked at every depth and shown by the CLI interview and the browser stack step like any other question. arch.framework stays retired and is not reused.
- The answer is stored in answers.yaml like every other answer and validated against the choices; a missing answer (older files, other pairs) means the default.
- Render: for the scaffold option, renderProfiles writes profiles/<p>/scaffold/ plus profiles/<p>/variants/<choice>/; the same path in both is an error. just, CI, guards and standards stay one per profile, so the variants share the uniform verbs. loadProfile checks that every choice has a variants folder.
- The CLI stack confirmation asks the option again when a changed runs-on lands on a profile with options. yaw edit can change the answer; the scaffold is user code written once at init, so a changed variant is not rewritten.
- A framework option is a library choice: its label says it overrides prefer built-in (arch.library-strategy).

## Consequences

One pair still maps to one profile; variants are folders, not profiles, so CI and guards are shared and must cover every variant. Changing the option after init does not swap the scaffold. Option names must be lowercase to form a question id.
