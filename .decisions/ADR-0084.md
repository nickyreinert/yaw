# ADR-0084: Give YAW a shared shark field-notebook visual identity

- **Date:** 2026-10-28
- **Category:** Architecture / Rendering
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/assets/**`
- **Tags:** design

## Context

The web UI needs a distinctive identity for YAW's friendly tiny shark, shared by setup, Settings and analytics.

## Decision

Keep component geometry in app.css and load a shared yaw-theme.css afterward in both web shells. Use navy ink, light chart-paper dots, cobalt, sunny yellow selected/action states, coral fin motifs, the friendly SVG shark and a waterline. Pair local Trebuchet-style headings with monospace metadata. Keep visible keyboard focus, semantic states and reduced-motion support; use local assets and font fallbacks.

## Consequences

Future UI work can reuse the brand tokens and motifs without changing flows or introducing remote font dependencies. Language choice labels are TypeScript and HTML, CSS and JavaScript; existing stored answer identifiers remain compatible.
