# ADR-0015: Phase-1 scope

- **Date:** 2026-10-20
- **Category:** Governance / Scope
- **Status:** Accepted
- **Importance:** high

## Context

BUILD.md step 1 and KICK-OFF.md listed items of later phases; the binding decisions BD3, BD6, BD7, BD8 settled the scope.

## Decision

- `yaw.db` holds only the session registry; evaluation tables, `release-plan.yaml` and phase gating are phase 2.
- `pr-policy` checks only that a PR links an open issue.
- `security` is minimal (secret-read deny, destructive-command guard); `quality-code` is phase 2.
- Agents: Claude Code, Codex, Copilot; Gemini CLI and others are phase 3. Nine profiles incl. `node-cli` for this repo; YAW's ADRs live in `.decisions/` from step 5.6.

## Consequences

No phase-2 format is defined now; adding one later is a new migration or schema, not a breaking change.
