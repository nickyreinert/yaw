# ADR-0109: No compat or legacy-answer code in pre-alpha

- **Date:** 2026-10-30
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0103

## Context

ADR-0103 renamed language javascript to typescript and added core/interview/legacy.js to keep old answers readable. The project is private pre-alpha with no users to migrate.

## Decision

- Delete legacy.js (migrateAnswers, currentValue) and its test; plain code paths in project, form-model, kickoff and host-projects.
- The language id stays typescript; old javascript answers are rejected like any unknown value.
- No compat or migration code in pre-alpha.

## Consequences

Old answers files, presets and API input saying javascript must be edited by hand.
