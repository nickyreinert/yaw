# ADR-0067: Learn navigation and classification that skips unavailable transcripts

- **Date:** 2026-10-27
- **Category:** Memory / Sessions
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/**`, `core/lib/session-analysis.js`
- **Tags:** learn

## Context

The user asked for a descriptive learning label and icon. A single missing saved transcript caused the entire filtered classification selection to fail and incorrectly pointed to classifier settings.

## Decision

Label the Global section and review-destination settings Learn, using a graduation-cap icon. Keep existing route and API identifiers compatible. Classification skips unavailable or unreadable transcripts individually, updates readable selected sessions only, and preserves prior rows and evaluations for skipped sessions. Report skip counts in both response and job progress, link recovery to session history folders, and call no model or write no scan when the entire selection is unavailable. Existing explicit classification, transcript-read and review-destination rules in ADR-0065 remain in force.

## Consequences

Saved metadata can outlive source histories; unavailable records remain useful statistics and may need history-folder correction or an explicit refresh. No implicit broad transcript discovery, review or model action is added. ADR-0066 programming-language hints and ADR-0007 hook output remain unchanged.
