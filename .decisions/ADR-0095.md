# ADR-0095: Use copy-only setup prompts, button choices and an authenticated agent setup API

- **Date:** 2026-10-29
- **Category:** Architecture / Rendering
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/**`, `core/lib/setup-prompts.js`, `core/cli/init.js`

## Context

The setup wizard previously required planning reply imports and hid setting context behind expanders. Users need manual and agent-driven configuration using the same validated settings.

## Decision

Use consistent monochrome icon buttons and a persistent active-setting help column. The optional external interview returns Architecture and Workflow recommendations for manual entry. Review automatically regenerates one final prompt instructing a local coding agent to create Architecture, Data Model and UI/UX directly. Remove reply/import and provider execution controls from setup cards while retaining CLI compatibility. Offer yaw init --api using the existing loopback login, CSRF, validation, preview and Apply transport; revisioned in-memory settings become browser handoff state on reload. A native MCP transport is outside this REST implementation.

## Consequences

Project facts and personal defaults stay separate. Existing saved architecture values and CLI plan imports remain readable. API updates alone never write files; Apply remains explicit. Browser and API clients are not live collaborative editors. Preserve ADR-0007 hook-output limits and ADR-0091 depth and adapter policies.
