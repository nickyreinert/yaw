# ADR-0023: `yaw add <module>`

- **Date:** 2026-10-21
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal

## Context

Doc 02 says `yaw add` asks only the module's questions; doc 04 says dependency violations are shown, not fixed.

## Decision

- Ask only the module's questions, previous answers as defaults; `--yes` takes the defaults.
- Refuse when a dependency is missing, naming the `yaw add` commands; never install dependencies.
- Render first, then write once; answers.yaml changes only when an answer is new or changed.
- `yaw remove` is the inverse; the answers stay.

## Consequences

A module with only S/F questions asks nothing in a Quick project.
