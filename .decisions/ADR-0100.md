# ADR-0100: Dock the interview console and share its folder tree with final review

- **Date:** 2026-10-30
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/**`, `core/remote/host-projects.js`

## Context

The interview file tree competed with the form, differed from the final review and had no complete-content preview. Step navigation retained the previous scroll position.

## Decision

Dock the compact, height-limited interview console and navigation above the full-width workspace status footer. Filter the console to affected paths and expand their folders; hide it on Review and Apply. Share folder hierarchy and purpose labels with the final review, which does not expose content previews. Resolve file content on demand from the current validated plan, returning planned or preserved existing text through authenticated read-only actions. Restrict previews to known files, 128 KiB, regular paths and content without detected secrets; refuse secret paths. Scroll explicitly to the form start while focusing the step heading.

## Consequences

Preview content stays local to the browser or its authorized hosted interview. No project write, external model call, hook output or tool-permission change is added.
