# ADR-0033: code-map module: maintained docs/code-map.md with generated sections, out-of-tree per-worktree cache, yaw map update/check/show, check in just check, lefthook and CI

- **Date:** 2026-10-21
- **Category:** Modules / Workflow
- **Status:** Proposed
- **Importance:** high

## Context

BUILD.md Step 5.11 asks for a version-controlled code map, a rebuildable local index, read-only freshness checks in the existing workflow, no GitHub dependency, no watcher and no model tokens beyond a short navigation rule.

## Decision

- Module code-map (depends core), Full only (ADR-0032); Quick gets it with yaw add. Git-hook and CI checks only where git-hooks / ci are installed.
- docs/code-map.md is managed: false (kept on remove): front matter declares areas, paths, entry points, tests, relationships, ADRs; generated sections between yaw:map markers list directories and declarations; maintained text outside markers stays byte for byte.
- Index cache in ~/.yaw/cache/code-map/<hash of worktree and git-dir real paths>.json, outside the tree; temp + rename, no lock; update compares before rename. Enumeration via git ls-files (tracked + untracked non-ignored) on every run, so branch and worktree changes need no hook.
- Exclusions before any open: ignored files, dependencies, build outputs, .yaw, security secretFiles patterns, symlinked components, submodules; O_NOFOLLOW.
- yaw map check is read-only and fails on stale sections, broken references and uncovered files with the repair command; show prints at most 40 lines. No agent hook; one AGENTS.md line (git-hooks block trimmed to one line to stay at 80).
- lefthook pre-commit job via the git-hooks frame flag; CI through quality-gate just check (no new job). Checks never stage, commit or push. Passing checks prove mechanical freshness, not the explanations; structural changes get a description review in the same PR.

## Consequences

Structural changes need a map update and review; the hook and just check see the working tree, CI the commit; symbol extraction and yaw map watch are later; orphan caches of deleted worktrees stay until removed by hand.
