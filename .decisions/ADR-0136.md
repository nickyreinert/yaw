# ADR-0136: Session classification v2, rules first: signals and phrase rules label obvious cases, Laya fills the rest as estimates

- **Date:** 2026-11-11
- **Category:** Memory / Sessions
- **Status:** Proposed
- **Importance:** normal
- **Supersedes:** ADR-0135
- **Scope:** `core/lib/session-analysis.js`, `core/web/**`
- **Tags:** classification, learn

## Context

ADR-0135 relied on Laya plus optional calibration. Section 12 verification (test/fixtures/laya/README.md) showed zero-shot Laya mislabels obvious cases with high confidence ("not what I asked, revert" -> new_topic p 0.97); temperature calibration cannot change the winning label, and fine-tuning would require users to label data first.

## Decision

Keep ADR-0135 (exchanges, two subjects, 1-5 scales, tags, per-exchange storage without text, sync of roll-ups only). Add English and German phrase and text rules (revert, shouting, repeated or cited instruction, admitted error, explicit verdict, frustration floor) with precedence signal > rule > model; every value stores its source and model values are shown as estimates. States are sent as JSON objects, the user state puts the reaction first. Calibration stays optional; no user training. Spec: kickoff/17-session-classification.md (revision 2026-11-11). Implementing it supersedes ADR-0068.

## Consequences

Obvious cases are labelled reliably without training; adherence, scope and complaint remain model estimates. Rules miss implicit wording and languages other than English and German. Phrase lists need maintenance and tests.
