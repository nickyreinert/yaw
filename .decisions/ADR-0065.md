# ADR-0065: Global Improve: classified project browsing, conversation reader and explicit review destinations

- **Date:** 2026-10-27
- **Category:** Memory / Sessions
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0064
- **Scope:** `core/web/**`, `core/lib/session-insights.js`, `core/lib/session-analysis.js`
- **Tags:** improve

## Context

The user found the Sessions Insights review confusing and explicitly requested Global Improve, recognition-based project/session selection, classification controls, real dialogue with highlighted clues and browser or configured installed CLI reviewers.

## Decision

Replace the Insights table UI with Global Improve, sharing Sessions filters, sorting, search and pagination. Lead with saved classified metadata and project/session views; retain unknown/mixed results and separate outcome from collaboration. Classification from Improve sends only matching saved local IDs and preserves other saved rows. A clearly labeled Read conversation action is the explicit transcript-read confirmation for that named session; display chronological messages with colored tentative phrase clues and previous/next navigation. Automatically prepare bounded relevant context in one editable review prompt, with no turn-count inputs or example checklists. Reuse interview browser chat links without prompt data in URLs. Global Settings Improve enables installed Claude Code or Codex reviewers and sets a default destination. Only explicit confirmed Run review starts a fixed headless CLI in a temporary directory with stdin prompt, tool restrictions, timeout and Stop; no shell commands from the browser, persistent evidence store, automatic changes or hook output.

## Consequences

Conversation reads remain capped at 8 MiB or 1000 messages; larger Gemini documents are unavailable. Phrase suggestions are unvalidated and selected context is not a population sample. CLI providers may be hosted and bill usage; users inspect the prompt before deliberate disclosure. Claude uses bare mode with tools disabled and no session persistence. Codex uses an ephemeral read-only session without user config, shell tools, apps, hooks or delegation. Provider-side retention is separate; YAW stores no transcripts, prompts or verdicts in analytics, registry, sync or logs. Server verdicts expire after 15 minutes; leaving or changing filters clears the review. ADR-0007, ADR-0018, ADR-0050, ADR-0053 and ADR-0061 remain in force.
