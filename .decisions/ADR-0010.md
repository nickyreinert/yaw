# ADR-0010: Task and record IDs per mode, branch names, recipe naming; `tasks` module details

- **Date:** 2026-10-21
- **Category:** Modules / Workflow
- **Status:** Proposed
- **Importance:** high

## Context

BD4 fixed where tasks live per mode; open were branch names, recipe names, the ADR ID scheme, journal lines when TASKS.md is a read-only view, and the Stop hook under rule 5.

## Decision

- IDs: local and both `T-NNN`, GitHub and team `#n`; branches `<type>/T-012-<slug>` or `<type>/34-<slug>`; ADR IDs sequential `ADR-NNNN`, in team mode `ADR-<issue>-<n>`.
- Recipes: `just task <verb>` (tasks), `just gh-*`, `just branch/commit/pr` (github); module recipes never reuse uniform verbs.
- GitHub mode: TASKS.md is a generated, git-ignored view; journal lines are issue comments.
- SessionStart re-injects the active task (context); the Stop reminder is comfort only (systemMessage).

## Consequences

Y-5.5 adds branch/commit/pr; Y-5.6 applies the ADR ID scheme; Y-5.7 reads the active task for session titles.
