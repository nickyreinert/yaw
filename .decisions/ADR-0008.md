# ADR-0008: Runtime floor, platforms and development tools

- **Date:** 2026-10-20
- **Category:** Delivery / Platform
- **Status:** Accepted
- **Importance:** high

## Context

BD11: macOS and Linux for v0.1, Windows via WSL only, Node ≥ 22.13 (`node:sqlite` without a flag), CI on Node 22 and 24.

## Decision

- Require Node ≥ 22.13 and git; just is recommended (warned); zero runtime dependencies, no `npm install` for users.
- Support macOS and Linux; Windows only through WSL.
- Dev tools: `node --test`, `shellcheck`, `lefthook` and `gitleaks` (module tests); no npm dev dependencies.
- Kit CI runs on ubuntu and macos with Node 22.13 and 24, plus install.sh in a Debian container.

## Consequences

Testing the floor catches newer Node APIs early; contributors without shellcheck still pass `npm test`.
