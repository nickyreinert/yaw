# ADR-0137: Make purpose optional in Git setup and isolate browser startup

- **Date:** 2026-11-18
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/cli/init.js`, `core/web/**`
- **Tags:** interview

## Context

Existing Git projects can already have purpose documented. The setup page exposed dashboard chrome while the interview and workspace data loaded.

## Decision

Amend ADR-0091 so existing Git projects can leave purpose empty in terminal, answers-file and browser setup. Keep the same rule when editing those answers. Show the current interview preparation stage on a dedicated startup screen and defer dashboard reads until the workspace UI is opened.

## Consequences

A blank purpose adds no purpose to generated instructions or README. The browser can expose setup before loading saved dashboard data. Language and runtime remain required.
