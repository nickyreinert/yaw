# ADR-0025: `devenv` module

- **Date:** 2026-10-21
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** low

## Context

Doc 04: `just setup/dev`, `.env.example`, Docker or a devcontainer only when the profile advises it.

## Decision

- No questions; `setup` and `dev` stay profile verbs; `setup` copies `.env.example` to `.env` when `.env` is missing.
- Always write `.env.example`; git-ignore `.env` and `.env.*` except the example.
- Container files only when the profile ships `devenv/` files.

## Consequences

Quick grows by one file (`.env.example`).
