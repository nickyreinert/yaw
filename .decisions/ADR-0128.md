# ADR-0128: node-static profile: TypeScript x static built with Vite; node-basic removed (T-001)

- **Date:** 2026-10-31
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `profiles/node-static/**`

## Context

T-001: TypeScript x static only had node-basic, which with node-web and node-app tailored covered just this pair. A basic profile needs one runsOn pair (ADR-0107), so node-basic is deleted. Differs from static-site (plain HTML, no build). Cited ADR-0102, ADR-0106.

## Decision

- node-static takes typescript x static. Scaffold: Vite 8 + strict TypeScript, index.html and src/main.ts wiring the DOM-free src/greeting.ts, Vitest, ESLint, exact-pinned dev dependencies.
- Gate: lint, typecheck, test, npm audit, vite build to dist/; no network beyond npm.
- Hosting is not generated; dist/ is what you upload. Guards: wrangler/netlify/vercel deploys, gh-pages, ssh/scp/sftp, rsync to a host, registry publishing.

## Consequences

A new project passes just check offline of any host. No deploy verb exists. node-basic and its tests are gone.
