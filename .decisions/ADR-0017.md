# ADR-0017: Format conventions (names, agent keys, facts, questions and answers)

- **Date:** 2026-10-20
- **Category:** Architecture / Formats
- **Status:** Accepted
- **Importance:** high

## Context

The docs show example files but leave identifiers and cross-file conventions open (F6, F7, F8, F10).

## Decision

- Names `^[a-z][a-z0-9-]*$`; agent keys `claude`, `codex`, `copilot` (phase 3 keys only in compatibility maps); session IDs `<agent>:<id>`.
- One facts vocabulary (`hasUI`, `language`, `runsOn`, `public`, `storesData`, `hosted`, `team`, ...) for `appliesTo`, `default` and `suggestWhen`.
- Question IDs `<group>.<name>`, inline in `module.yaml`; answers are stored by question ID; no secret question types or IDs.
- Hooks in `module.yaml` are `{ name, event, matcher, kind, agents, tokenCost }`.

## Consequences

One validator and one answer model serve CLI, form, presets and user profile.
