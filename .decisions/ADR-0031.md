# ADR-0031: team module: issue-required guards, lefthook commit-msg / pre-push, pr-policy check, verified rulesets, session-start sync

- **Date:** 2026-10-21
- **Category:** Modules / Workflow
- **Status:** Proposed
- **Importance:** high

## Context

Doc 14 §2-§3 asks for team-mode enforcement in layers; BD3 limits pr-policy to the open-issue rule; BUILD.md rule 5 allows the model only the active task at session start; guarded GitHub writes need a person at a terminal (ADR-0027).

## Decision

- A team module (Standard and Full for a team; depends on tasks, github, git-hooks) owns the enforcement; removing it removes every layer.
- PreToolUse guards deny edits off an issue branch or on a diverged branch, and git commit/push to the default branch, force pushes, --all/--mirror, --no-verify (also as prefixes) and core.hooksPath overrides; while diverged, rebase/pull/merge/reset/upstream changes are left to the user; one-line reason, nothing on allow.
- lefthook commit-msg needs #<n>; pre-push is a script so lefthook cannot skip it; pr-policy.yml checks closingIssuesReferences for an open issue of this repository, read-only, no action.
- gh protect applies stay guarded; --verify only reads. SessionStart: fetch, fast-forward only when clean and not ahead, gh reads cached 5 min in ~/.yaw/cache, offline fail-open; the user gets a systemMessage, the model one active-issue line.

## Consequences

Git calls in simple commands (with shell keywords, wrappers and sh -c) are parsed; scripts, aliases and eval are left to the git hooks, pr-policy and the ruleset. closingIssuesReferences is empty for PRs into other branches. No just sync, Project fields or phase rules yet.
