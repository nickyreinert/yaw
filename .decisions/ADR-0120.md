# ADR-0120: Profile just files define the core verbs; optional verbs (screenshot, preview-share, db-*, backup, restore, deploy) only when implemented

- **Date:** 2026-10-30
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0020
- **Scope:** `profiles/**`
- **Tags:** justfile

## Context

Generated projects carried up to 8 'not applicable' stub recipes per profile (ADR-0020 required every profile to implement all uniform verbs), which is bloat and noise in just --list.

## Decision

- Core verbs every profile defines: setup, dev, fmt, lint, typecheck, test, check, build, audit.
- screenshot, preview, preview-share, db-migrate, db-reset, backup, restore and deploy exist only where the profile really implements them; no echo-only stubs.
- The composed root justfile calls an optional verb only on the profiles that define it.
- Unchanged from ADR-0020: profile files are owned by core (just fragment with import, .gitignore part, scaffold written once as managed false); check = lint typecheck test audit sync-check; rule-based suggestion; init = collect, confirm, apply, verify.

## Consequences

Smaller justfiles; a missing optional verb fails with just's own unknown-recipe error. Tests assert absence of stubs.
