# ADR-0078: Extend existing Improve diagnosis with explicit verdict retention and reviewed instruction additions

- **Date:** 2026-10-28
- **Category:** Memory / Sessions
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/lib/improve-store.js`, `core/web/assets/insights-view.js`, `core/web/workspace-api.js`

## Context

Global Improve already supports model-generated diagnosis using configured installed reviewers under ADR-0065. The user requested the deliberately deferred features as well.

## Decision

Extend the existing review runner without replacing it. Offer optional structured outcome, collaboration and adherence estimates with evidence and a candidate instruction; absent task context means unknown adherence. Explicitly save or import verdicts into a private separate history, never analytics, registry or sync. Default retention is 30 days with 7/30/90/365 choices, expiry on access, deletion and JSON export. Omit the edited review prompt unless separately included. Review instruction additions in an exact diff and require explicit Apply to a fixed project AGENTS.md or project/personal review-rules target. Append only, reject stale previews, secret-like text and symlinks, and preserve the AGENTS line budget.

## Consequences

Verdicts and instructions remain unverified model estimates until reviewed. No automatic rule application, background model invocation or new hook output is added. Deleting a record removes retained prompt text but does not revert applied instructions. Store at most 100 records with bounded text. Existing temporary reviews expire as before unless explicitly saved. Empirical validation of clues and recommendation usefulness remains open.
