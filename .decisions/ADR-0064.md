# ADR-0064: Bounded temporary Insights review in Sessions

- **Date:** 2026-10-27
- **Category:** Memory / Sessions
- **Status:** Superseded
- **Importance:** normal
- **Scope:** `core/lib/session-insights.js`, `core/web/assets/insights-*.js`
- **Tags:** insights
- **Superseded by:** ADR-0065

## Context

The user requested implementation of CONCEPT.md. Existing saved label counts cannot reconstruct exchanges, and automatic recommendations have not been validated.

## Decision

Attach Insights review to the existing filtered Sessions tables. Confirm each explicit read of one to five local saved sessions. Discover filenames only, then inspect at most 8 MiB or 1000 messages per selected session; skip larger Gemini JSON documents. Suggest up to five tentative phrase or ordinary comparison examples per session, allow explicit manual turn reads, and include bounded original/preceding/following context with omissions marked. Users select and redact up to five examples, preview and edit the exact package, then copy a maximum 24000-character prompt requesting one verdict sentence and at most three bullets within 150 words. No model call or persistent evidence store is added.

## Consequences

Phrase hints are unvalidated and supported languages are limited; no quantitative advice is generated. Saved aggregate coverage includes unknown, mixed, skipped and unclassified records with classified-turn denominators. Synced or missing local evidence stays usable as metadata. Reviews clear on navigation, filter changes or refresh; copying to an external service is deliberate disclosure. ADR-0018, ADR-0050 and ADR-0007 remain in force; implements the first scope proposed in ADR-0062.
