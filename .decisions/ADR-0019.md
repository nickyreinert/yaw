# ADR-0019: Phase-1 CLI surface and the behaviour of the step-2 commands

- **Date:** 2026-10-20
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal

## Context

The docs name many `yaw` commands but no list (S2), the minimal step-2 `init` was open (S3), and ADR-0003 left flag names open.

## Decision

- Fixed phase-1 command list. Amended by user decision (2026-10-24, before launch): `apply` is the primary rendering command; `update` remains an alias. `config` and `session` are removed, without placeholder help or compatibility messages.
- `parseArgs` in strict mode; exit 0 on success, 1 on every error, refusal or conflict; prompts only on a terminal.
- `apply [--yes] [--strategy keep|take|merge] [--restore p] [--forget p]` (also `update`); `remove <module>` shows its plan and keeps edited files without an explicit flag.
- `edit [<section|question.id> ...] [--web] [--list] [--skip-verify]` reviews saved interview answers in the terminal or browser with current values as defaults, then previews and confirms before reconciliation. Section editing preserves unrelated answers and cannot change depth, profiles or modules. Full editing can change depth, profiles and agents; installed modules stay unless explicitly changed in the full browser editor. User-edited files are kept. Concurrent setup changes require reopening the editor.
- `doctor` and `status` report kit, manifest, files and tools.
- `web` (added with #172, ADR-0050) opens the dashboard (one shared server for all YAW projects, ADR-0044 amendment), or the setup form when the folder has no YAW setup.
- `knowledge list|show|add|edit|remove` (added 2026-10-24, ADR-0053 amendment) manages global and current-project knowledge records; `remove` confirms unless `--yes`.
- `kickoff [import <plan.md> [--dry-run]]` (added with #173) prints the planning prompt and imports the plan through `task new`.
- Bare `yaw`, `yaw --help` and `yaw help` group implemented commands into project setup and maintenance, planning and project work, monitoring and collaboration, YAW internal commands, and agent integration helpers. Each command appears exactly once. Knowledge-namespace settings and native agent-session renaming remain deferred.

## Consequences

A new phase-1 command needs an update here. Deferred ideas remain in the build plan, not the CLI.
