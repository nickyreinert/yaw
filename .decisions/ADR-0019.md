# ADR-0019: Phase-1 CLI surface and the behaviour of the step-2 commands

- **Date:** 2026-10-20
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal

## Context

The docs name many `yaw` commands but no list (S2), the minimal step-2 `init` was open (S3), and ADR-0003 left flag names open.

## Decision

- Fixed phase-1 command list; a planned command says "comes with step N" and exits 1.
- `parseArgs` in strict mode; exit 0 on success, 1 on every error, refusal or conflict; prompts only on a terminal.
- `update [--yes] [--strategy keep|take|merge] [--restore p] [--forget p]`; `remove <module>` shows its plan and keeps edited files without an explicit flag.
- `doctor` and `status` report kit, manifest, files and tools.

## Consequences

Later steps fill in rows of the existing command list; a new phase-1 command needs an update here.
