# ADR-0049: Guarded optional GitHub planning automation

- **Date:** 2026-10-23
- **Category:** Modules / Workflow
- **Status:** Accepted
- **Importance:** high

## Context

Issue #110 extends task workflows while preserving offline local work and explicit authorization for Project and milestone changes.

## Decision

Generate issue forms and issue-create, issue-triage and epic-plan skills. With project.number configured, GitHub task start/done preflight and confirm Status changes to In progress/In review. Explicit epics issue-to-milestone mappings drive guarded task sync for each epic and its direct native sub-issues; never infer milestones from arbitrary titles. Local/both start and done remain offline. Profile dependencyEcosystems drives namespaced Dependabot entries.

## Consequences

Missing fields or permissions fail explicitly; refusal precedes task mutations. Live GitHub verification stays deferred, while tests inject synthetic CLI output. Forms store planning answers in bodies, not automatically labels or Project fields. Terminal confirmation retains ADR-0048 limitations.
