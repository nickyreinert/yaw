# ADR-0116: Profiles declare third-party tools in an optional tools list (T-004)

- **Date:** 2026-10-30
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/render/kit.js`, `profiles/*/profile.yaml`

## Context

Stacks like php-serverless (bref) need tools such as the AWS CLI that users learn about only when a command fails. Extends ADR-0105 (options) and the requires list.

## Decision

profile.yaml gets an optional tools list: name, check command, install per macOS/Linux, optional when {option: choice}. The CLI and web setup show the applicable tools when the profile is picked; yaw init prints those whose check fails, with the install command. Proof: php-serverless, rust-serverless, node-app.

## Consequences

Check commands run via sh at the end of init only. More profiles add tools as they are tailored. Install strings are advice, never executed.
