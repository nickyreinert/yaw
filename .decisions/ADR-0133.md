# ADR-0133: Compact recall store: raw output of cut tool results kept locally in ~/.yaw/recall

- **Date:** 2026-11-08
- **Category:** Modules / Comfort
- **Status:** Deprecated
- **Importance:** high
- **Scope:** `modules/compact/lib/recall.js`, `modules/compact/lib/run.js`

## Context

kickoff/16-compact-output.md §4 L6 keeps the raw text of a cut tool result so that an agent can read it again instead of re-running a step that may be flaky or have side effects. It is the first place YAW stores tool-output content, which can hold secrets, personal data and proprietary code.

## Decision

- Optional `recall` value of the `compact.levers` question, off by default and never set by `YAW_COMPACT=1`. Without it nothing is stored and a cut output ends with `re-run with YAW_VERBOSE=1 for the full output`.
- With it, the raw output of a cut result is stored as `~/.yaw/recall/<hash>.gz` (hash: first 16 hex digits of the SHA-256 of the raw bytes) and the output ends with `full output: yaw recall <hash>`. `yaw recall <hash>` prints it.
- Private by the rules of the hook logs: directory 0700, files 0600, owned by the user, written through an exclusive temporary file renamed into place, opened without following symbolic links.
- At most 200 entries (oldest removed first), 30 days, and 10 MB of raw output per entry (a larger output is not stored; the re-run hint is shown). Read-back refuses entries that inflate beyond 10 MB.
- Never synced: data sync lists the files it takes by name and never reads the recall directory.
- Only output that is actually cut is stored. Wrapper (`yaw run`, T-055) first; the compress hook (T-054) reuses `storeRecall`.

## Consequences

The raw text stays on the machine that ran the command, unencrypted, for up to 30 days, readable by anyone who can read the user's account; see NOTICE-0002. A committed project answer containing `recall` makes every teammate's machine store output; whether recall should be settable only as a personal choice is open. Rejected on 2026-11-08: the owner dropped the recall store (T-055). Nothing is stored; a cut output ends with the `YAW_VERBOSE=1` re-run hint. The code, `yaw recall` and the `recall` lever were removed, and NOTICE-0002 was withdrawn.
