# ADR-0082: Share cascading Analytics filters and preserve Sessions links

- **Date:** 2026-10-28
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/**`
- **Tags:** analytics

## Context

Workspace Analytics, Global Analytics and Global Overview need the same six-column filtering flow.

## Decision

Use one multi-select browser ordered Device, Folders, Projects, Programming language, Agent and Model. Combine values with OR within a column and AND across columns; earlier columns constrain later lists and incompatible later selections are cleared. Preserve repeated filter parameters in URLs. Canonical views are analytics and global-analytics; legacy sessions routes remain aliases. Synced rows expose unavailable paths rather than invented projects.

## Consequences

Date controls and operations follow the lists. Filters stay in document flow. Backend session APIs and stored data retain their names.
