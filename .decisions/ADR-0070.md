# ADR-0070: Extend the implemented CLI surface with the private remote service

- **Date:** 2026-10-28
- **Category:** Architecture / CLI
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0019
- **Scope:** `core/cli/main.js`, `core/cli/remote.js`, `test/cli.test.js`

## Context

ADR-0019 fixed the phase-1 command list. The user now requested implementation of the remote-control concept, recorded in ADR-0069.

## Decision

Extend the implemented command list with yaw remote serve, sync and status. Group remote once under Monitoring and collaboration. Preserve the strict parseArgs interface, success/error exit codes, terminal confirmation conventions, apply/update aliases, scoped/full edit behavior, read-only doctor/status, dashboard web, knowledge and kickoff commands, and grouped help described in ADR-0019. Deferred config and session commands remain absent. Remote credentials are environment inputs, never CLI arguments; remote setup, migration and real execution require explicit actions.

## Consequences

The remote command is discoverable without changing existing CLI behavior. New commands must update the command table, help groups and CLI surface test together.
