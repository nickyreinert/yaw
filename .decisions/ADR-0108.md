# ADR-0108: node-app drops the Expo variant; frameworks capacitor, electron, tauri

- **Date:** 2026-10-30
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0106

## Context

ADR-0106 shipped four framework variants. The Expo variant needed a critical-only npm audit exception (zod 3, deepmerge) that lowered the audit bar.

## Decision

- Remove variants/expo, the expo option choice, the node-app-expo example and CI entry, eas guard, .expo ignores.
- Remove the critical-only audit special case; every variant audits at the default level.
- Rest of ADR-0106 stands for capacitor, electron and tauri.

## Consequences

No audit exception; Expo/React Native is no longer offered.
