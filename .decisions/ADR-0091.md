# ADR-0091: Quick includes agent and GitHub choices; Gemini is a supported setup adapter

- **Date:** 2026-10-29
- **Category:** Architecture / Rendering
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0080, ADR-0015
- **Scope:** `core/interview/**`, `core/web/**`, `core/render/**`, `adapters/**`
- **Tags:** interview, agents

## Context

Quick hid agent selection and GitHub; Gemini remained disabled by an obsolete phase marker despite a supported rules import and shared skill convention.

## Decision

Quick asks coding agents, purpose, language, runtime and GitHub. Its About you step exposes only coding agents, and its Workflow step exposes only the GitHub toggle. Saved/factory defaults govern all other fields and optional tools remain off unless previously selected. Basic adds personal preferences, collaboration, task and review controls; Pro exposes all applicable choices with runtime applicability from ADR-0090. Preserve explicit project answers across depth/presentation changes and separate project ground truth from reusable kit practices. Make Gemini selectable in every depth: generate GEMINI.md importing AGENTS.md and use shared .agents/skills. Report native rules/skills support and explicit command/rules fallbacks; do not claim or register native YAW Gemini hooks. Keep ADR-0007 hook-output limits. Older phase labels do not gate this implemented adapter.

## Consequences

The five Quick choices are consistent across terminal and browser. Gemini-only projects receive working rules and skills without Claude/Codex settings or credential handling. Other architecture constraints and project foundations retain their existing review and approval boundaries.
