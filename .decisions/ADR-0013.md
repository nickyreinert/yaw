# ADR-0013: Personal vs. committed configuration; hygiene opt-out

- **Date:** 2026-10-21
- **Category:** Modules / Catalogue
- **Status:** Proposed
- **Importance:** normal

## Context

Team repositories share every generated file, but the communication style is one person's preference (M7, M14).

## Decision

- Treat `user.*` answers (except `user.agents`) as personal, project rules as committed.
- In team or external-reviewer projects the `communication` module writes nothing (no AGENTS.md section, no output style).
- Session hygiene is on by default but personal and can be switched off (Y-5.8).

## Consequences

`templateContext` exposes `team`; Y-5.8 keeps comfort configuration out of committed files.
