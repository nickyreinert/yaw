# ADR-0086: Keep product UI copy terse and action-oriented

- **Date:** 2026-10-28
- **Category:** Architecture / Rendering
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/web/assets/**`
- **Tags:** design, copy

## Context

The user rejects explanatory prose such as the planning card introduction and wants this avoided throughout the product UI.

## Decision

Use concise labels, controls and factual status in product screens. Remove narrative and promotional paragraphs, redundant instructions and duplicated explanations. The shared planning card follows this rule in setup, completion and Settings. Retain actionable errors, review requirements and concise billing or execution notices. Generated LLM prompts and project documentation may still contain the detail needed to perform the work.

## Consequences

Future UI changes must follow this copy rule; AGENTS.md carries the standing instruction. Planning keeps its existing options, review and save behavior with less visible copy.
