# ADR-0027: `github` and `ci` modules

- **Date:** 2026-10-21
- **Category:** Modules / Workflow
- **Status:** Proposed
- **Importance:** high

## Context

Doc 10 and doc 14 describe GitHub scripts, labels, issue types, rulesets and a quality gate; agents must not be able to run the dangerous ones.

## Decision

- `yaw gh <verb>` behind `just gh-*`, `just branch/commit/pr/release`; `gh` and `git` with argument arrays, never a shell.
- Guarded actions (init, labels, protect, project-add, release, first push) need a person typing `y` on a terminal; there is no `--yes`; no verb merges, force-pushes, deletes branches or changes visibility.
- Native issue types with a `type:` label fallback; one ruleset on the default branch.
- `quality-gate.yml` installs the kit at the manifest tag, runs `just check` and a pinned gitleaks scan; every action is pinned by SHA.

## Consequences

Raw `gh` calls and agents with a pseudo-terminal are known limits (#112, #113).
