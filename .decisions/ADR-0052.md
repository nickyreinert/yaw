# ADR-0052: Local web workspace: guided setup, maintenance, and metadata-only cross-project session profiling

- **Date:** 2026-10-24
- **Category:** Architecture / CLI
- **Status:** Superseded
- **Importance:** normal
- **Scope:** `core/web/**`
- **Superseded by:** ADR-0053

## Context

The web entry previously split setup and a flat dashboard, making maintenance and historical cross-project analysis hard to discover, especially before initialization.

## Decision

Both entry states share an overview and navigation for setup, maintenance, session profiling, tasks and decisions. Setup uses six revisitable steps and the existing explicit save/apply transport. Authenticated read-only workspace data is available before setup. Profiling filters registry metadata by project, agent, model and time range before aggregating, bounds only the recent display list, and reports usage/cost coverage. Maintenance inspects non-secret manifest files and shows terminal commands without running project recipes. Native history import remains an explicit per-project terminal action; outcome evaluation and OTel remain planned.

## Consequences

No new dependencies, persistence tables, collection, permissions or telemetry. Unknown usage and duration remain visible. Missing registries are not created by viewing. Existing local handshake, CSRF, offline assets, and apply confirmation remain intact.
