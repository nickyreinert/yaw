# ADR-0062: Insights concept: connected outcome and collaboration evidence, manual LLM review, concise verdicts

- **Date:** 2026-10-26
- **Category:** Memory / Sessions
- **Status:** Proposed
- **Importance:** normal
- **Scope:** `CONCEPT.md`
- **Tags:** insights, session-analysis

## Context

Session totals and aggregate labels do not explain repeated corrections or show which request, instruction, task or session habit could improve.

## Decision

Concept direction only, not implementation approval: connect task outcome with collaboration quality while keeping them separately visible; distinguish measured quantities from estimated signals and causal hypotheses; let users select and redact a few contextual exchanges and manually copy a review prompt to their chosen LLM; request one verdict sentence and at most three actionable bullets. Keep YAW-managed inference loopback-only, conversation evidence temporary, registry and analytics metadata-only, and changes to instructions explicit.

## Consequences

Apologies and short prompts are clues, not proof of user error. Quantitative advice needs comparable groups, denominators and coverage; candidate selection and context limits still need validation. Manual export is a deliberate disclosure and adds no automatic external model call or hook output.
