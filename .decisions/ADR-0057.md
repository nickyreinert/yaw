# ADR-0057: Manual portable data sync and device-attributed numerical statistics

- **Date:** 2026-10-25
- **Category:** Architecture / CLI
- **Status:** Superseded
- **Importance:** normal
- **Scope:** `core/lib/data-sync.js`, `core/cli/sync.js`, `core/web/**`
- **Superseded by:** ADR-0060

## Context

The user wants shared presets and settings plus statistics merged across named devices, available in the Web UI and CLI; native session transfer is excluded because paths and agent state differ.

## Decision

Preserve yaw sync --check (ADR-0012). Add manual setup/run/status and Global Settings Sync with shared three-way merging, explicit conflicts, deletion markers and allowlisted settings/preset records. Export only hashed session identity and numerical summaries, deduplicate overlapping observations by greatest message count, and retain per-device provenance. Use an existing folder or private GitHub repository. Keep machine-dependent answer fields local; no transcripts, source code or credentials are copied. No collection hooks or implicit scans are added (ADR-0007, ADR-0053).

## Consequences

Statistics on Sync are separate from local session charts. Private destinations contain plaintext portable data. GitHub needs authenticated gh and Git; diverged clones and stale crash locks require manual recovery. Full sessions and arbitrary machine settings remain outside scope.
