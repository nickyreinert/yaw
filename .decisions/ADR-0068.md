# ADR-0068: Learn outcome evidence rules and UNKNOWN diagnostics

- **Date:** 2026-10-28
- **Category:** Memory / Sessions
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `core/lib/session-analysis.js`, `core/web/**`
- **Tags:** learn, classification

## Context

Task completion charts had many UNKNOWNs. Live synthetic checks showed that five-way label names and more verbose instructions alone could leave explicit acceptance uncertain or wrong.

## Decision

Keep one explicit local classification pipeline. Use concise outcome criteria and optional complete preceding context within the existing byte limit. Narrow English/German whole-message user verdict rules supply fulfilled, not_fulfilled or abandoned labels; absent feedback and bare thanks remain unknown. Qualified, quoted or longer feedback goes to Laya. Preserve the original model choice and confidence in previews and identify rule-derived applied labels separately. Save aggregate UNKNOWN reasons and rule-use counts only; keep the confidence threshold unchanged and retain legacy results until explicit reclassification.

## Consequences

Exact phrase rules cover limited wording and languages; contextual Laya predictions remain experimental. User-reported acceptance does not verify code or tests. Synthetic checks demonstrate specific fixes rather than population accuracy. Conversation text stays temporary, existing loopback and confirmation requirements remain, and no hooks or automatic evaluation are added.
