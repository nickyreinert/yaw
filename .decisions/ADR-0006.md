# ADR-0006: Kit resolution, hook shim, versioning, pre-tag install

- **Date:** 2026-10-20
- **Category:** Delivery / Platform
- **Status:** Accepted
- **Importance:** high

## Context

One global kit in `~/.yaw/kit` serves every project; hooks must find it without `yaw` on the PATH and must fail open; projects pin a kit version (U4, H7, S4, BD10).

## Decision

- Install the kit as a git clone in `~/.yaw/kit` and link `~/.local/bin/yaw`; never use sudo or edit shell profiles.
- Pick versions by `--tag`, `--channel main`, the last channel, else the latest `v*` tag; before the first tag use `--channel main`.
- One global kit: newer than the pin → `yaw doctor` warns; older → writing commands refuse.
- Hooks call `.yaw/bin/yaw-hook` (POSIX sh, committed): vendored lib, else `${YAW_KIT:-$HOME/.yaw/kit}`; no Node or no kit → exit 0, no output. CI installs the pinned tag.

## Consequences

Every machine runs one kit; a project can lag behind it, never run ahead of it.
