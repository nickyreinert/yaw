# ADR-0106: node-app profile: TypeScript x app-store with framework variants capacitor, expo, electron, tauri; gate without Xcode, Android SDK or signing

- **Date:** 2026-10-30
- **Category:** Modules / Catalogue
- **Status:** Accepted
- **Importance:** normal

## Context

T-003 first use of profile options (ADR-0105). node-basic covered typescript x app-store with no framework. Each framework needs a gate that runs on a plain Linux runner.

## Decision

- node-app takes typescript x app-store from node-basic; option framework (default capacitor, label says it overrides prefer built-in) selects variants/<choice>/; scaffold/ holds the shared greeting, Vitest test, vitest and ESLint config.
- Uniform verbs; lint (eslint), typecheck (tsc --noEmit), test (vitest), build (npm run build), audit (npm run audit) are the same recipes for every variant, each variant's package.json supplies dev, build and audit.
- Builds: capacitor and tauri run vite build; electron runs vite build plus tsc for the main process; expo runs expo export for android and ios (Metro bundle only). No native projects: cap add, tauri init (src-tauri, Rust) and prebuild are left to the user.
- Exact pins checked with npm view on 2026-10-30 and installed together: @capacitor/core and @capacitor/cli 8.6.0, @tauri-apps/api and @tauri-apps/cli 2.12.4, electron 45.1.0, expo 58.0.21 with react 19.3.0, react-native 0.88.1 (expo bundledNativeModules), @types/react 19.3.0, vite 8.3.5, vitest 5.0.5, typescript 6.0.3, eslint 10.13.0, @eslint/js 10.0.1, typescript-eslint 8.72.0, @types/node 22.20.5.
- Expo audit runs at --audit-level=critical: expo 58 pulls zod 3 (high, fixed only in zod 4) and deepmerge (low, no fix) through @expo/cli; the other variants audit at the default level.
- Guards: store uploads (eas submit/build/update, fastlane, xcrun altool/notarytool, iTMSTransporter), signing (codesign, jarsigner, apksigner, signtool, keytool, security import, tauri signer), release publishing (electron-builder --publish, electron-forge publish, gh release create/upload), registry publishing, just deploy, remote hosts. deploy only prints a note.
- CI: examples node-app, node-app-expo, node-app-electron, node-app-tauri join the kit-ci profile matrix; smoke tests per variant in test/profiles.test.js.

## Consequences

A typescript app-store project gets a real framework scaffold and a gate that needs no Apple or Google tooling. The Expo audit exception lowers the audit bar for that variant until expo moves to zod 4 (needs a user decision to keep). Native shells, signing and store builds are untested by the kit.
