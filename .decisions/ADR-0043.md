# ADR-0043: User folder ~/.yaw: opt-in after the interview (default no), standing yes once the profile exists, answers-only presets, secret refusal by security rules

- **Date:** 2026-10-22
- **Category:** Architecture / CLI
- **Status:** Proposed
- **Importance:** normal

## Context

Y-7.2 (#71) needs the opt-in prompt, ~/.yaw layout, yaw presets and history.jsonl (doc 02 section 5, P8). The docs fix the layout but not when the prompt appears, how a no is remembered, what is saved, or how secrets are detected; the security module has secret file-name rules but no value rules.

## Decision

Asked once after apply, interactive interview only, default no; --answers never asks or writes. A no writes nothing, so it is asked again next time; the existence of user-profile.yaml is the standing yes and later interviews save without asking. Saved: user-profile.yaml (user.* keys of the schema, merged), a preset named YYYY-MM-DD-<folder> with all answers, mode and source, and one history.jsonl line {path,date,kit,preset}; all validated against their schemas first; files 0600, folders 0700 (chmod also when they exist). Nothing is saved if any answer key is not a valid question id (secret-type words) or any value hits the new secretValues rules of modules/security/guards.yaml (token prefixes, private key block, JWT, URL credentials, name=value) or the existing secretFiles rules (value is a bare file name like .env); the refusal names key and rule, never the value, and the summary hides such a value. Presets: list, show, delete; names match the preset schema (no path traversal); delete asks (default no) or needs --yes. HOME comes from the command environment. The saved profile is not yet read back to prefill an interview (start screen is the form, Y-7.3/7.4).

## Consequences

Adds secretValues to guards.schema.json and guards.yaml (hooks ignore it), core/lib/user-store.js and core/cli/presets.js. Pattern rules cannot catch every secret; a bare long random string is not detected. A secret typed into an answer still lands in the project's .yaw/answers.yaml (secret entry is Y-7.6). Doc 02 5, doc 03 0, doc 08 3 and plan row Y-7.2 follow.
