      Data sources & coverage
      Pages read saved results only; Refresh (or Auto) reads Claude Code, Codex and Copilot CLI local history, and Classify runs local Laya. Scan limit: 20,000 files per agent. Transcripts of any size are read completely; single lines over 4 MiB and broken lines are skipped and the session is marked partial. Unchanged transcripts are reused from the last scan, so rescans only read new or changed files. Missing usage/cost is shown as —. Duration is elapsed time, not active work. Response time is prompt-to-first-recorded-answer, not network latency. Charts use UTC days. Classification is experimental, can be wrong, and never runs automatically. Turns above the configured size are skipped rather than truncated.
