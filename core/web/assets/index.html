    Collect & classify
    Saved results only until you explicitly scan. Scanning reads local message records for aggregate lengths and timing; message text is not saved. Classification sends turn text only to local Laya, never a hosted API.
    
        
    
        
    Data sources & coverage
    Explicit scans support Claude Code, Codex and Copilot CLI local history. No scan on page load unless you enable refresh-on-load. Scan limit: 20,000 files per agent; analysis limit: 64 MiB and 2,000 text messages per transcript. Missing usage/cost is shown as —. Duration is elapsed time, not active work. Response time is prompt-to-first-recorded-answer, not network latency. Activity uses UTC days. Classification is experimental, can be wrong, and never runs automatically. Oversized turns are skipped rather than truncated.
